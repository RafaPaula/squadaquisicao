Login

POST 
https://auth.inhire.app/login

Este endpoint permite que os usuários autentiquem-se na aplicação utilizando seu e-mail e senha. Além disso, é necessário incluir o X-Tenant ao cabeçalho.

Request​

  • application/json
  • Body
  • Login with email and password

Bodyrequired

    emailemailrequired

    Endereço de e-mail do recurso.

    passwordstringrequired

    Senha do usuário (apenas em requests, nunca em respostas).

    Possible values: >= 6 characters and <= 64 characters

{
  "email": "{{email}}",
  "password": "{{password}}"
}
