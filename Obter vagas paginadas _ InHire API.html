Obter vagas paginadas

POST 
https://api.inhire.app/jobs/paginated/lean

Este endpoint retorna vagas de forma paginada.

É possível enviar parâmetros para definir a quantidade de vagas a ser retornada e a partir de qual vaga iniciar a paginação, utilizando a identificação de uma vaga.

Request​

Header Parameters

    X-Tenant stringrequired

    Multi-tenant identifier. Required on every request. This determines which tenant's data the request operates on. Maps to the DynamoDB partition key (tenantId).

    Example: acme-corp
  • application/json
  • Body
  • Example (auto)

Bodyrequired

    exclusiveStartKey objectnullable

    Cursor para a próxima página. Em null ou ausente na primeira chamada. Em chamadas subsequentes, deve ser exatamente o objeto startKey recebido na resposta anterior — não monte manualmente.

    property name*anynullable

    Cursor para a próxima página. Em null ou ausente na primeira chamada. Em chamadas subsequentes, deve ser exatamente o objeto startKey recebido na resposta anterior — não monte manualmente.

    limitnumber

    Tamanho máximo da página. Para listar tudo, recomende valores altos (ex. 500). Para diagnóstico, use valores baixos (ex. 10).

{
  "exclusiveStartKey": {},
  "limit": 0
}
