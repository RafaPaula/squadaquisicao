Listar talentos paginados

POST 
https://api.inhire.app/talents/paginated

Este endpoint retorna uma lista paginada de talentos com capacidade de filtrar por data de criação ou atualização.

Request​

Header Parameters

    X-Tenant stringrequired

    Multi-tenant identifier. Required on every request. This determines which tenant's data the request operates on. Maps to the DynamoDB partition key (tenantId).

    Example: acme-corp
  • application/json
  • Body
  • Example (auto)

Bodyrequired

    exclusiveStartKey object

    Cursor opaco para paginação cursor-based do DynamoDB. Passe o valor recebido no response anterior para obter a próxima página.

    idstring

    Identificador único do recurso (ULID).

    createdAtstring

    Timestamp ISO-8601 de criação do recurso.

    updatedAtstring

    Timestamp ISO-8601 da última atualização do recurso.

    tenantIdstring

    Identificador do tenant (cliente InHire) ao qual o recurso pertence.

    orderBy object

    Campo usado para ordenar os resultados.

    fieldstringrequired

    Identificador / chave do campo (custom field ou form field).

    Possible values: [createdAt, updatedAt]

    directionstringrequired

    Direção da ordenação (asc ou desc).

    Possible values: [asc, desc]

    filter object

    Filtro aplicado à busca/listagem.

    createdAtdate-time

    Timestamp ISO-8601 de criação do recurso.

    updatedAtdate-time

    Timestamp ISO-8601 da última atualização do recurso.

{
  "exclusiveStartKey": {
    "id": "string",
    "createdAt": "string",
    "updatedAt": "string",
    "tenantId": "string"
  },
  "orderBy": {
    "field": "createdAt",
    "direction": "asc"
  },
  "filter": {
    "createdAt": "2024-07-29T15:51:28.071Z",
    "updatedAt": "2024-07-29T15:51:28.071Z"
  }
}
